# TFG guidance knowledge base

This directory is the fast, agent-readable index of the UPV/ETSINF material supplied under
`../../../instrucciones_recomendaciones_normativa_documentación_plantillas/`. It exists so normal
work can use a concise Markdown reference instead of extracting every PDF on every session.

It is intentionally layered:

- [`academic-rules.md`](academic-rules.md): binding rules, integrity, ODS, deposit, and
  administrative cautions.
- [`writing-and-defence.md`](writing-and-defence.md): recommended GCD thesis structure,
  inherited ETSINF/GII writing guidance, Overleaf workflow, and defence guidance.
- [`evaluation.md`](evaluation.md): transversal competencies, working rubric, and the evidence
  the project should preserve.
- [`../../../proyecto/docs/research-protocol.md`](../../../proyecto/docs/research-protocol.md):
  project-specific experimental and reproducibility contract derived from the approved scope and
  academic criteria.
- [`source-index.md`](source-index.md): coverage and purpose of every supplied source/asset plus
  the current official web sources used to resolve operational or superseded material.

## Authority and precedence

1. Binding UPV regulations and later amendments prevail over recommendations and old slides.
2. GCD-specific ETSINF guidance prevails when it addresses the same concept as inherited GII
   guidance.
3. GII material remains applicable to shared ETSINF concepts where GCD guidance is silent.
4. Current Ebrón screens, current call/calendar, and tutor/CAT instructions prevail for changing
   operational details such as deadlines, required uploads, and defence logistics.
5. These summaries are derived guidance. For exact wording or a high-stakes administrative
   decision, open and cite the original source.

The local collection was reviewed and this knowledge base was created on 2026-08-14. The full
academic-compliance matrix and official web sources were revalidated on 2026-09-03. That review
confirmed the 2026 UPV amendment, current Ebrón cover/deposit behaviour, the five-competency UPV
model, the current tutor report, the September 2026 calendar, and the formal
matrícula-de-honor conditions. When any source is replaced or a new regulation is added, review the
affected Markdown document before relying on it.

## Relationship with `AGENTS.md` and GSD

`AGENTS.md` contains short, durable operating rules and points here. It must stay concise enough
to load on every task; it should not contain the full academic handbook.

GSD contains project state: goals, requirements, decisions, phases, plans, progress, and
verification. GSD should link to this knowledge base and the separate project research protocol
rather than copy either one. This avoids stale parallel versions.

Use the original PDFs only when:

- exact wording, a deadline, a legal requirement, or a form field matters;
- two derived statements appear inconsistent;
- current Ebrón/ETSINF behaviour may have changed;
- a quotation or page-specific citation is required; or
- the source files have changed since this knowledge base was reviewed.
